# 🎬 Netflix Landing Page Clone

A modern, responsive clone of the **Netflix Landing Page** built from scratch using pure HTML5, CSS3, and Vanilla JavaScript to master responsive UI architecture and modern CSS techniques.

🔗 **Live Demo:** [https://parasjain02.github.io/Netflix-Clone/](https://parasjain02.github.io/Netflix-Clone/)

---

## ✨ Features Built So Far

### 1. 🌟 Hero Section & Navigation
- **Authentic Netflix Branding:** Responsive logo, customized language dropdown selector, and red call-to-action buttons.
- **Cinematic Vignette:** Multi-stop linear gradient overlay on top of high-res hero backdrop image.
- **Mobile-Responsive Form:** Stacked input fields and scaled typography for small devices.

### 2. 🔴 Iconic Curved Arch Divider
- **Elliptical Dome Arch:** Curved border-radius dome bridging the Hero section and Section 1.
- **Deep Ambient Glow:** Custom multi-stop radial gradient fading from deep midnight navy to pitch black (`#000000`).
- **Viewport Clipping Engine:** Center-anchored flex setup (`max(100%, 1200px)`) that cleanly clips edges on smaller screens without squishing the curve.

### 3. 🍿 "Trending Now" Top 10 Interactive Carousel
- **Horizontal Movie Slider:** Smooth horizontal scrolling with custom hidden scrollbars (`scrollbar-width: none`).
- **Ranked Top 10 Numbers:** Iconic oversized numbers (1–10) styled with CSS text strokes (`-webkit-text-stroke`) overlapping movie posters.
- **Dynamic Navigation Controls:** Floating translucent arrow buttons with hover micro-interactions.
- **Smart Toggle Logic:** JavaScript automatically switches button visibility depending on scroll position.
- **Mobile Touch-Optimized:** Desktop navigation buttons hide automatically on phones to provide a native swipe/touch experience.

---

## 🛠️ Tech Stack & Concepts Practiced

- **HTML5:** Semantic markup (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- **CSS3:**
  - Flexbox layouts (`justify-content`, `align-items`, `flex-shrink`, `flex-grow`).
  - Advanced Gradients (`linear-gradient`, `radial-gradient` color stop easing).
  - Absolute & Relative positioning with Z-indexing.
  - Media queries (`@media (max-width: 600px)`).
  - CSS Text Stroke & Typography.
  - Smooth transitions & Hover states.
- **JavaScript (Vanilla):**
  - DOM manipulation for dynamic language selection.
  - Programmatic smooth scrolling (`element.scrollBy()`).
  - Conditional button visibility state handling.

## 🚀 How to Run Locally

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/ParasJain02/Netflix-Clone.git
   ```
2. Open the project folder in **VS Code**.
3. Right-click on `index.html` and choose **"Open with Live Server"**.
