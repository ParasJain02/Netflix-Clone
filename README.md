# 🎬 Netflix Landing Page Clone

A responsive clone of the Netflix landing page built from scratch to practice modern web development concepts.

## ✨ Features
- **Fully Responsive:** Adapts to mobile, tablet, and desktop screens.
- **Hero Section:** Features the iconic dark gradient overlay and centered email signup form.
- **Interactive Elements:** JavaScript-powered dropdown menu for language selection.
- **Modern Layouts:** Built using CSS Flexbox for clean, predictable alignment.
- **Mobile Optimized:** Custom media queries and "safe zones" to prevent layout breaking on landscape phones.

## 🛠️ Tech Stack
- **HTML5:** Clean, semantic structure.
- **CSS3:** Flexbox, media queries, absolute positioning, and custom hover states.
- **JavaScript:** Vanilla JS for DOM manipulation and interactive UI elements.

## 🚀 How to Run Locally

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/ParasJain02/Netflix-Clone.git
   ```
2. Open the project folder in **VS Code**.
3. Right-click on the `index.html` file.
4. Select **"Open with Live Server"** (Requires the Live Server extension by Ritwick Dey).
